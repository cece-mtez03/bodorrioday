# BodorrioDay · Conchi & Sergio

Primera versión en HTML + CSS + JavaScript.

## Estructura

- `index.html` → estructura de la web.
- `css/styles.css` → estética, responsive y animación 3D.
- `js/app.js` → interacción de apertura.
- `assets/doors-horizontal.png` → ilustración horizontal de las puertas.

## Abrir en VS Code

1. Abre esta carpeta en VS Code.
2. Instala/usa la extensión **Live Server** si la tienes.
3. Botón derecho sobre `index.html`.
4. `Open with Live Server`.

También puedes abrir `index.html` directamente en el navegador, aunque Live Server es más cómodo para desarrollar.
